# Security

Report a suspected vulnerability privately to [ziaurrahman.26261@gmail.com](mailto:ziaurrahman.26261@gmail.com). Include the affected page and enough information to reproduce the issue. Do not include patient information, credentials, or other sensitive records in a report or a public GitHub issue.

This repository is the public Meddot brochure website. The consultation form prepares an email draft and does not automatically send or store submissions. It must not be used to collect protected health information.

Dependency update pull requests and automated security/quality checks are configured in `.github/`. Updates require review and a passing production build; automatic merging is not configured.
